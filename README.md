# 🏗 Drill Master: Нафтогазовий Інженер

**Drill Master** — це професійний інженерний симулятор буріння нафтових та газових свердловин, який фокусується на максимальній фізичній точності та глибокій взаємозалежності параметрів.

## 🚀 Як запустити

Симулятор написаний на Python і не потребує сторонніх бібліотек для роботи базового двигуна (використовує стандартні модулі `math`, `time`, `termios`).

1. Переконайтеся, що у вас встановлений **Python 3.10** або новіше.
2. Склонуйте репозиторій.
3. Запустіть головний файл:

```bash
python3 main.py
```

*Примітка: Для коректного відображення кольорів та ASCII-графіки рекомендується використовувати сучасний термінал (iterm2, Windows Terminal, VS Code Terminal).*

## 🎮 Управління

| Клавіша | Дія |
| :--- | :--- |
| **W / S** | Збільшити / Зменшити навантаження на долото (WOB) |
| **A / D** | Збільшити / Зменшити оберти ротора (RPM) |
| **Q / E** | Збільшити / Зменшити подачу насосів (Flow Rate) |
| **Space** | Перейти до наступної стадії (всього 31 стадія) |
| **X** | Вийти з гри |

## ⚙️ Інженерні особливості

У симуляторі реалізовані справжні фізичні моделі:

- **Гідравліка**: Розрахунок втрат тиску за моделлю Бінгем-Пластік, обчислення числа Рейнольдса та коефіцієнта тертя (діаграма Муді).
- **Механіка буріння**: Швидкість проходки (ROP) розраховується через MSE (Mechanical Specific Energy) та модель Уоррена.
- **Геологія**: Процедурна генерація пластів з урахуванням UCS, Young Modulus, Poisson Ratio та градієнтів пластового тиску.
- **Well Control**: Реальна модель ГНВП (Kick) на основі недокомпенсації тиску та проникності пласта.

## 🧠 ШІ Консультант

Ваш інженерний консультант аналізує стан свердловини кожну ітерацію. Він не просто каже, що ROP впав, а пояснює чому:
> "AI Diagnostic: Pack-off risk! Cleaning efficiency is only 45%. Cuttings are regrinding, not being removed."

## 📂 Структура проекту

- `engine/` — Математичні ядра (гідравліка, механіка, безпека, економіка).
- `models/` — Моделі даних (геологія, шари).
- `tests/` — Набір юніт-тестів для перевірки фізики.
- `main.py` — Головний цикл гри та TUI інтерфейс.
- `DOCS_LIFECYCLE.md` — Детальний опис усіх 31 стадій життя свердловини.
